# memo

一个本地使用的中文笔记网站：直接新建笔记（照片可选），手动整理条目，记录每一步进展。

## 启动

Windows 安装 Python 3.11 或更高版本后，双击 `start.bat`。首次启动需要网络安装依赖。看到服务启动成功后，在浏览器打开 http://127.0.0.1:8000 。以后启动无需联网。使用期间保持启动窗口开启，按 Ctrl+C 停止服务。

也可以手动启动：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

## 使用

1. 在「新建笔记页」填写标题即可创建；也可上传 JPG、PNG 或 WebP 照片（最大 20 MB）。照片会校正方向并保存为 JPEG，不保留原文件元数据。
2. 添加条目；点击「更新条目」编辑文字和状态，点击「保存修改」。
3. 输入进度并点击「记录进展」，时间由本机时区记录。状态变化也会追加历史记录。
4. 点击「查看大图」放大查看照片。删除条目或整页前会要求确认，并先移入回收站。

每次提交立即保存；尚未点击保存的文字不会自动保存。没有账号、OCR、云端同步或遥测。

左侧按最近更新时间排序，新增、修改、删除条目或记录进展都会更新所属笔记的时间。每页可点击「置顶／取消置顶」，最多置顶 5 页；置顶组始终显示在普通组上方，两组内均按最近更新时间排序。

顶部「收起列表／展开列表」控制左栏显示；左栏顶部可新建笔记，并切换「全部／收藏」。每页点击「☆ 收藏」或「★ 已收藏」可收藏或取消收藏，收藏不限数量且独立于置顶。收藏保存在数据库；左栏开关及筛选偏好保存在当前浏览器。

## 搜索、标题、回收站与标签

- 左栏搜索框查找笔记标题、条目、进度历史及标签中的文字；可以与标签筛选组合使用。搜索不识别照片中的文字，也不包含回收站内容。
- 笔记标题下方「修改标题与标签」可修改整页标题；更新后按最近更新时间排序。
- 标签用中文或英文逗号分隔，每页最多 10 个，每个最多 30 字；删除输入框里的标签并保存即可移除。点击标签或左栏下拉框可筛选。
- 「移入回收站」保留照片、条目、进度与标签。通过左栏「回收站」恢复，或确认后彻底删除。整页恢复时保留收藏，但不自动恢复置顶；此前已单独删除的条目仍在回收站。
- 回收站没有自动清理期限。只有彻底删除才会移除数据库记录及对应照片；旧备份不受影响。

## 备份与恢复

先按 Ctrl+C 关闭服务，再将整个 `data` 文件夹复制到另一个磁盘或备份位置。数据库是 `data/memo.db`，照片是 `data/uploads/`，两者必须一起备份。

恢复时先停止服务，将当前 `data` 文件夹重命名保留，然后把备份的完整 `data` 文件夹复制回项目目录，重新启动即可。不要在运行时复制数据库，也不要只备份照片或数据库其中之一。

## 技术与限制

FastAPI + Jinja2 + SQLite + 普通 CSS / JavaScript。服务默认只监听本机；这是单人本地应用，请勿直接开放到公网。使用固定地址和一个服务进程。程序重启后，旧页面需要刷新再提交。

## 验证

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 代码结构与主题

应用按 View、Controller、Service、Model 分层。阅读顺序和一次完整请求的示例见 [ARCHITECTURE.md](ARCHITECTURE.md)。启动方式和本地数据格式保持兼容。

右上角可切换「黑红主题／浅色主题」。黑红主题采用深色背景和红色强调，偏好保存在当前浏览器。
